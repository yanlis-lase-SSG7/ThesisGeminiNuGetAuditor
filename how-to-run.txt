Cara Menjalankan GeminiNuGetAuditor

1. Pastikan .NET 10 SDK sudah terinstall.

2. Siapkan autentikasi Vertex AI dengan Google Cloud Application Default Credentials:

   PowerShell:
   gcloud auth application-default login

   Salin appsettings.example.json menjadi appsettings.json, lalu isi:
   - ProjectId: project Google Cloud Anda
   - Location: lokasi Vertex AI, misalnya us-central1
   - Model: gemini-2.5-pro

3. Jika ingin memakai GitHub Advisory Database real-time, siapkan GitHub token:

   PowerShell:
   $env:GITHUB_TOKEN = "your-github-token"

   Jika token tidak tersedia atau request GitHub gagal, aplikasi tidak memakai fallback lokal atau appsettings.
   Project tersebut ditandai RETRIEVAL_FAILED dan dikeluarkan dari perhitungan metrik.

4. Dependency CodeBERT tidak perlu di-install manual. Pada run pertama, aplikasi membuat
   virtual environment lokal .codebert-venv dan menjalankan pip install otomatis dari
   Scripts\CodeBert\requirements-codebert.txt.

   Aplikasi memakai baseline real lokal
   LOCAL_CODEBERT_EMBEDDING_LOGREG berbasis encoder CodeBERT dan Logistic Regression.
   Jika Python tidak tersedia atau bootstrap dependency gagal, aplikasi tidak membuat prediksi sintetis.
   Skenario CodeBERT ditandai CODEBERT_FAILED dan dikeluarkan dari perhitungan metrik.

5. Jalankan aplikasi tanpa argumen:

   dotnet run

6. Saat console menampilkan prompt berikut:

   Please enter the folder path containing the .csproj files to audit:

   Masukkan folder root yang berisi file .csproj, contoh:

   D:\path\to\solution-or-project-folder

7. Aplikasi akan:

   - mencari semua file .csproj secara rekursif;
   - membuat folder hasil baru di dalam audit-results, contoh audit-results\20261231 14-15-16;
   - melewati project yang sudah memiliki checkpoint JSON di folder checkpoints milik run tersebut;
   - memproses banyak project secara paralel;
   - menjalankan Zero-Shot, retrieval ground truth, RAG-LLM, dan CodeBERT Python bridge;
   - menyimpan report JSON, HTML, CSV, dan Excel ke folder audit-results.

8. Output utama:

   audit-results\20261231 14-15-16\audit-rag-llm-<timestamp>.json
   audit-results\20261231 14-15-16\audit-zero-shot-<timestamp>.json
   audit-results\20261231 14-15-16\audit-codebert-<timestamp>.json
   audit-results\20261231 14-15-16\audit-comprehensive-metrics-<timestamp>.csv
   audit-results\20261231 14-15-16\audit-comprehensive-report-<timestamp>.xlsx
   audit-results\20261231 14-15-16\audit-interactive-report-<timestamp>.html
   audit-results\20261231 14-15-16\api-diagnostics-<timestamp>.json
   audit-results\20261231 14-15-16\console-execution-log-<timestamp>.json
   audit-results\20261231 14-15-16\checkpoints\<project-key>.json

Catatan:

- Jalankan aplikasi tanpa argumen CLI.
- Jika Gemini API gagal untuk sebuah skenario, status skenario menjadi API_FAILED.
- API_FAILED tidak memakai ground truth sebagai prediksi pengganti dan tidak dihitung ke confusion matrix.
- Jika CodeBERT gagal karena Python tidak tersedia atau bootstrap dependency gagal, status skenario menjadi CODEBERT_FAILED dan tidak dihitung ke confusion matrix.
- Untuk memproses ulang satu project di folder run yang sama, hapus checkpoint JSON project tersebut dari folder checkpoints.
- Format folder memakai tanda hubung pada jam-menit-detik karena karakter ":" tidak valid untuk nama folder Windows.
